## Đọc sâu mã nguồn — 08/11/2026

Action handler, event queue và timeline của stategraph.

Mức đối chiếu của phần này là `source-traced-partial`.

- PushEvent ghi tên state hiện tại vào dữ liệu rồi xếp hàng. HandleEvent ưu tiên handler ở currentstate, sau đó mới handler cấp graph. HandleEvents dừng duyệt nếu callback thay bảng sự kiện và cuối lượt xóa hàng cũ.
- GoToState kiểm tra state tồn tại trước; gọi onexit cũ, tạo statemem/tag mới, cập nhật tag entity ở master, xóa timeout, đặt thời gian state về 0 rồi onenter và newstate.
- UpdateState trừ timeout trước timeline. Nếu ontimeout đổi state thì trả ngay. Timeline chạy các mốc đã tới theo chỉ số; callback đổi state hoặc đưa thời gian lùi làm Update lại phần thời gian dư. Onupdate chạy sau timeline.

**Lưu/tải.** statemem bị tạo mới mỗi lần đổi state. Dữ liệu cần giữ lâu phải nằm ở entity/component hoặc cơ chế persist riêng.
